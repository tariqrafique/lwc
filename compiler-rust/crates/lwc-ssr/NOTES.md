# lwc-ssr notes
- Sync lock: template emit is sync-only. Body lines are `__lwcYield += ...;` inside `export default function __lwcTmpl(...)`; no `yield`/`async`.
- `compile_template_for_ssr(&Root, &TemplateTransformOptions) -> CompileResult { code, map: None }`.
- IR: `lwc_shared::template_ir` (RATIFIED, owned by Template). Text via `TextValue`; root `PreserveComments` directive overrides option. Text + Element/ExternalComponent (static+dynamic attrs, void set hardcoded) ported; Comment (preserve), legacy If (if:true/false -> `if (!c)`), lwc:if/elseif/else chain (with `<!---->` bookends; isSlotted not tracked so always bookended) ported. ForEach (`for (let [index|__unused__, item] of Object.entries(expr ?? {}))`) and ForOf (`for (let it of toIteratorDirective(expr ?? []))`, imports toIteratorDirective) ported. Slot ported (prefers `slot_name`). Component ported in sync form (component.rs): properties→childProps, attributes→childAttrs (bool attr→`''`), module `ChildComponentCtor_<camel>` from `x/fooBar`, `Ctor[SYMBOL__GENERATE_MARKUP]` else `fallbackTmplNoYield`; children hoisted as `__shadowSlotN` shadow default slot. GAP: lightSlottedContentMap/scopedSlottedContentMap always null (slot-attr mapping, scoped fragments TODO); `shadow_fns` unused. lwc:component uses `lwc:is` expr as Ctor, else emits throw. Identifiers -> `instance.<name>` unless root identifier is in the scope stack (`sc: &mut Vec<String>` threaded through emit; for:each pushes item+index, for:of pushes iterator; truncated after children). Complex expressions are not rebound (opaque `(src)`). Dynamic class uses normalizeClass, no scope token yet; static attrs escaped at compile time.
- Stylesheet rendering (`renderStylesheets`) not emitted yet.
- `runtime_abi.rs` freezes runtime export names.
